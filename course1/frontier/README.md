# course1/frontier

Model diagrams for the frontier notebook, referenced by this commit's raw URL. Every number on them is checked
against the real model's configuration by a cell in the notebook.

- `fr_depth_anything.png`, Part 2. Depth Anything V2 Small: patches, the DINOv2 encoder, four layers to the DPT decoder, the head.
- `fr_speecht5.png`, Part 3. SpeechT5 text to speech: the encoder, the decoder loop with the speaker x-vector, the
  post-net, the HiFi-GAN vocoder.
- `fr_sdxl.png`, Part 4. SDXL: two text encoders, the U-Net in the latent space with cross-attention and the
  pooled text vector, the scheduler loop, the VAE decoder.
